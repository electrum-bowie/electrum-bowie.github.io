## VR Controls

Hold both controller grip buttons to move and scale the loaded splat. Moving the controllers changes the position of the splat while their distance controls the scale.

Hand tracking is also supported through WebXR. Make sure your browser session requests the `hand-tracking` feature and allow hand tracking permissions in the Quest. Once inside VR mode, close your hands into fists ("grip close" gesture) with both hands to start manipulating the splat, similar to squeezing the controller grips.
